## 1. 역추적 시스템

### 개념

> 해킹을 시도하는 해커의 **실제 위치를 실시간으로 추적**하는 기술

공격자는 보통 자기 IP를 바로 노출하지 않고 중간 서버나 좀비 PC를 거쳐 공격함.

```
해커 → 좀비 PC → 중간 서버 → 우리 서버 (공격 발견)
                               ↑
                         여기서 역방향으로 추적
```

### TCP 연결 역추적

| 유형 | 설명 |
|------|------|
| **호스트 기반** | 개별 컴퓨터의 연결 정보를 조사 |
| **네트워크 기반** | 네트워크 장비·트래픽을 분석 |

## 2. ESM (통합보안관리시스템)

### 개념

> 방화벽, IDS, IPS, VPN 등 **여러 보안장비의 로그를 한곳에 모아 통합 관제**하는 시스템

```
방화벽 ─┐
IDS ────┤
IPS ────┼──→ ESM ──→ 보안관리자
VPN ────┤
웹방화벽─┘
```

각 장비가 따로 만드는 로그를 ESM이 모아서 **상호 연관 분석**을 수행함.

> 예: "방화벽에서 이상 접속 + 같은 시간 IDS에서 침입 탐지 → 공격 판단"

### ESM 구성요소

| 구성요소 | 역할 |
|---------|------|
| **ESM 에이전트** (클라이언트) | 각 보안장비에 탑재. 로그·이벤트 수집 후 ESM 매니저로 전송. 정책도 받음 |
| **ESM 매니저** (서버) | 통합 보안정책 생성·적용·관리. 이벤트 분석 및 관리자에게 보고 |
| **ESM Event Log Repository** | 에이전트가 수집한 이벤트·로그를 저장하는 **로그 DB** |

```
각 보안장비
    ↓
ESM 에이전트 (수집하는 일꾼)
    ↓
ESM 매니저 (분석·관리하는 관리자)
    ↓
Event Log Repository (로그 창고)
```

### ESM 주요 기능

- 통합보안관제
- 통합 로그관리
- 이벤트 필터링
- 실시간 통합 모니터링 및 경보 전파
- 로그 분석 및 의사결정 지원
- 긴급대응
- 리포팅
- 통합운영관리 (보안정책 관리, 보안감사, 이력관리, 권한관리)

## 3. UTM (통합보안시스템)

### 개념

> **여러 보안 기능을 하나의 장비에 통합**하여 제공하는 보안 솔루션

```
        ┌─────────────┐
        │    UTM      │
        │  방화벽     │
        │  IDS/IPS    │
        │  VPN        │
        │  웹 필터링  │
        │  이메일 필터│
        └─────────────┘
```

---

## 4. ESM vs UTM 비교

> ⭐ 시험에서 자주 비교 출제

| 구분 | **ESM** | **UTM** |
|------|---------|---------|
| 핵심 개념 | 여러 보안장비를 **통합 관리** | 여러 보안 기능을 **하나의 장비에 통합** |
| 장점 | 이기종 보안장비 통합 관리 가능 | 관리 용이, 공간 절약 |
| 단점 | 로그가 많고 관리 복잡 | 장애 발생 시 **전체 기능에 영향** |

## 5. NAC (네트워크 접근제어)

> ⭐⭐⭐ **매우 중요**

### 개념

> "이 단말, 우리 네트워크에 들어와도 되는 장치 맞아?" — **접속 전 보안 상태를 검사하고 통제**하는 시스템

```
단말 접속 시도
     ↓
NAC 검사
     ↓
① 등록된 장치인가? (MAC 주소 확인)
② 보안 프로그램 설치됐나?
③ 패치 제대로 됐나?
④ 보안 정책 준수하고 있나?
     ↓
   OK?
 ↙     ↘
허용   차단
```

### 필요성

과거에는 회사 PC만 연결됐지만, 지금은 노트북·스마트폰·태블릿·IoT 등 다양한 단말이 연결됨
→ "아무 장치나 들어오면 위험하다" → NAC 필요

### 주요 기능

| 기능 | 설명 |
|------|------|
| **접근제어/인증** | IP 기반 장치의 네트워크 접근 제어 |
| **무결성 체크** | 백신 설치 여부, 패치 현황 등 보안 상태 확인 |

### NAC 구성

- **MAC 주소** 기반으로 단말을 식별하고 접근 통제
- 라우터로 구분된 서브네트워크마다 에이전트 시스템 설치

```
등록된 MAC 주소 목록
AA:BB:CC:11:22:33 → 허용 ✅
AA:BB:CC:44:55:66 → 허용 ✅
AA:BB:CC:77:88:99 → 차단 ❌
```

## 6. SIEM

### 개념

> 수많은 시스템·보안장비의 **로그를 수집·분석**하여 이상 징후를 파악하고 경영진에게 보고하는 시스템

```
서버 ──┐
방화벽 ─┤
DB ────┤
IDS ───┼──→ SIEM ──→ 이상 징후 탐지 ──→ 관리자 알림
웹서버 ─┤
VPN ───┘
```

### 주요 기능

| 기능 | 설명 |
|------|------|
| **데이터 통합** | 여러 출처의 데이터를 한곳으로 수집 |
| **로그 수집** | 다양한 시스템·장비의 로그 수집 |
| **로그 변환** | 제각각인 로그 형식을 **표준 포맷으로 통일** |
| **상관관계 분석** ⭐ | 개별 이벤트를 연결해 보안 위협 패턴 발견 |
| **알림** | 이상 이벤트 발생 시 관리자에게 자동 알림 |
| **대시보드** | 이벤트 데이터를 시각화하여 패턴 제공 |

> **로그 변환 예시**
> ```
> A 장비: 2026-08-15 LOGIN USER=ABC
> B 장비: [15/Aug/2026] abc login success
> → 표준 포맷으로 통일해서 분석
> ```

> **상관관계 분석 예시**
> ```
> 방화벽 → 이상 접속 탐지
>        +
> 서버  → 로그인 실패 100회
>        +
> DB    → 비정상 SQL 요청
>        ↓
> SIEM → "이거 공격이다!"
> ```

**대표 제품:** QRadar, ArcSight, Splunk

### ESM vs SIEM 비교

| | ESM | SIEM |
|--|-----|------|
| 초점 | 보안장비 **통합 관제** | 로그 **수집·분석** 및 이상 탐지 |
| 주요 기능 | 정책 관리, 이벤트 관제 | 로그 정규화, 상관관계 분석 |

## 7. SOAR

### 개념

> SIEM이 공격을 **발견**한다면, SOAR은 **자동으로 대응**하는 시스템

```
SIEM
 ↓
공격 발견
 ↓
SOAR 자동 대응
 ├─ 공격 IP 차단
 ├─ 계정 잠금
 ├─ 방화벽 정책 변경
 ├─ 담당자 알림
 └─ 티켓 생성
```

- 가트너(Gartner) 정의: SOA(보안 오케스트레이션), SIRP(보안 사고 대응), TIP(위협 정보 플랫폼)을 포괄하는 개념
- **자동화된 통합보안관제 솔루션**이라고도 함

### SIEM vs SOAR 비교

| | SIEM | SOAR |
|--|------|------|
| 역할 | 위협 **발견·분석** | 위협 **대응·자동화** |

## 8. PMS (패치관리시스템)

### 개념

> 수백·수천 대의 컴퓨터에 보안 패치를 **중앙에서 자동으로 관리·배포**하는 시스템

```
          PMS (중앙 관리)
              ↓
 ┌────────────┼────────────┐
 ↓            ↓            ↓
PC 1         PC 2         PC 3
 ↓            ↓            ↓
패치         패치          패치
```

### 패치 단계

#### ① 패치 준비 단계

```
패치 수신 (보안채널 or USB 등 물리적 매체 사용)
             ↓
     안전성·무결성 검증
     ("믿을 만한 패치인가? 변조되지 않았나?")
             ↓
     패치 대상 시스템 선정 및 목록 작성
```

> ⚠️ 패치 수신은 **인터넷 직접 연결이 아닌** 보안채널 또는 물리적 저장매체를 사용

#### ② 패치 분배 단계

```
패치 대상 PC 선정
     ↓
시간·단계별 순차 배포
(예: 1차 100대 → 2차 300대 → 3차 600대)
     ↓
설치 성공?
↙          ↘
YES         NO
 ↓            ↓
완료        복구 기능 실행
```

## 9. 전체 요약

### 기술별 한줄 정리

| 기술 | 한마디 |
|------|--------|
| **역추적 시스템** | 공격자의 위치·경로를 거꾸로 추적 |
| **ESM** | 여러 보안장비를 통합 관리·관제 |
| **UTM** | 여러 보안 기능을 하나의 장비에 통합 |
| **NAC** | "너 안전해?" 검사 후 네트워크 접속 통제 |
| **SIEM** | 로그 수집·분석 → 공격 발견 |
| **SOAR** | 공격 발견 → 자동 대응 |
| **PMS** | 패치를 중앙에서 관리·배포 |

### 전체 흐름으로 이해하기

```
여러 보안장비 / IT 시스템
        ↓
     로그 발생
        ↓
  ESM / SIEM (수집·분석)
        ↓
   이상 징후 탐지
        ↓
      SOAR (자동 대응)
```

### NAC 핵심 흐름

```
단말 접속 시도
     ↓
NAC (MAC 주소 확인 + 보안 상태 검사)
     ↓
허용 or 차단
```

### PMS 핵심 흐름

```
패치 수신 (보안채널)
     ↓
무결성 검증
     ↓
대상 선정
     ↓
순차 배포 + 오류 시 복구
```
